✨ 快速开始
  1. 去「🗂️ 分类管理」确认分类列表是否 OK，排序可以拖拽调整；分类编码留空会自动生成。
  2. 去「🎁 商品管理」点右上角「➕ 新建商品」，录入名称 / 价格 / 库存（SKU 留空也会自动生成哦）。
  3. 需要换图：在新建/编辑商品弹窗的「主图 R2 key」一行，点「📷 选图上传」，即可直接选图上传并自动填入 key，无需离开弹窗。
  4. 商品卖出去啦：去「📦 库存盘点」用 SKU 快速搜索，一键登记销售扣库存，前台库存立即同步为真实数量。
  5. 保存成功后去前台刷新，就会看到新的分类、商品与真实库存啦 💖
